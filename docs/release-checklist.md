# OpenTerm release checklist

- `make verify` passes on supported macOS and Linux versions.
- Terminal, provider, evidence, plugin, and SSH security reviews pass.
- Complete Apache-2.0, MIT, RTK, Ghostty, and dependency notices ship.
- OpenTerm name, package-store, repository, and domain clearance is complete.
- Signing, notarization, update verification, and rollback are exercised.
- Accessibility, reduced-motion, keyboard, and contrast audits pass.
- Migration, corruption recovery, crash reconnect, and soak tests pass.
- No credentials or secret-bearing fixtures exist in artifacts.
