v0.1.0 · alpha · macOS

The terminal that
speaks to your model

OpenTerm is a native terminal built on Ghostty with a Rust core. It shrinks noisy command output before your AI sees it, keeps every byte as encrypted evidence, and lets you use any model, including the Claude or ChatGPT plan you already pay for.

Get started Download v0.1.0

Built for humans and agents

⚡

Answers stream instantly

All providers stream: Claude, OpenAI, Mistral, Groq, Ollama, Claude Code and more. Settings load once per command, and requests reuse pooled connections.

🗜

Token-aware commands

39 ai-* wrappers send test runs, linters, diffs and logs through RTK, so your model reads the signal instead of 40k tokens of noise.

🔐

Lossless, encrypted evidence

Every managed run gets a res_… reference. Full output is kept with XChaCha20-Poly1305 and can be expanded later without rerunning.

🧭

Context without pasting

ai-ask attaches cwd, Git state and redacted shell files, answers in markdown, and can apply edits through OpenCode.

🔄

Models stay current

ai-models discovers models from each provider's own endpoint and refreshes stale lists in the background. Model ids are never hard-coded.

🖥

Native, not Electron

Metal rendering, tabs, splits, a SwiftUI settings pane with a model picker, and an agent side panel that streams answers.

Big outputs stay home

Install

1

Get the CLI

curl -L -o openterm.tar.gz \
  https://github.com/RemiPelloux/openterm/releases/latest/download/openterm-macos-arm64.tar.gz
tar xzf openterm.tar.gz && cd openterm
./install.sh   # links ai-* into ~/.local/bin
2

Connect a model

ai-connect                     # arrow-key wizard
printf %s "$GROQ_API_KEY" | ai-connect groq --model llama-3.3-70b-versatile --key-stdin
ai-connect claude-code         # uses your Claude Pro/Max login
3

Ask, with context

ai-ask "why does cargo test take 40s?"
ai-test cargo test             # compressed, with a res_… reference
ai-explain --last              # explain the last result

Want the full native app? Build OpenTerm.app from source.
